# Error Contract

On any documented `error_type`, **hard stop**. Show `error_type`, failed stage,
and direct remediation. Stage 6 cleanup still runs.

## GitHub CLI error codes

`gh-auth-failed`, `permission-denied`, `diff-fetch-failed`,
`discussions-fetch-failed`, `no-review-rule`, `artifact-write-failed`,
`post-failed`, `unexpected-error`.

## Local workflow error codes

`invalid-pr-url`, `ambiguous-pr-url`, `workspace-mismatch`,
`worktree-failed`, `worktree-permission-denied`, `codegraph-init-failed`,
`subagent-unavailable`, `prompt-injection-detected`,
`review-validation-failed`.
